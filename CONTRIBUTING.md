# Contributing to Patna Run Club Website

Thank you for your interest in contributing to the Patna Run Club community platform!

## Development Workflow

1. Fork or clone the repository
2. Create a new feature branch (`git checkout -b feature/amazing-feature`)
3. Install dependencies (`npm install`)
4. Make your changes and verify with `npm run dev` and `npm run lint`
5. Commit your changes using descriptive commit messages (`git commit -m 'feat: add event countdown timer'`)
6. Push to your branch and submit a Pull Request

## Code Style & Standards

- Adhere to Next.js App Router conventions.
- Keep components modular and accessible using Radix UI primitives.
- Format code cleanly according to `.editorconfig`.
