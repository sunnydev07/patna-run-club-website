# 🏃 Patna Run Club Website

A modern, high-performance web application built for the **Patna Run Club** community using Next.js 15, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Hero & Motion Design**: Dynamic bento grid layouts and smooth scroll-driven visual narratives.
- **Training Methodology**: Interactive schedules for interval training, endurance runs, and mobility sessions.
- **Run Programs & Community Events**: Information on weekly runs, track sessions, and half marathons.
- **Responsive Layout**: Built for mobile, tablet, and desktop viewports.
- **SEO & Accessibility**: Structured metadata, semantic HTML, and accessibility features.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, CSS Variables
- **Icons**: Lucide React
- **Deployment**: Vercel / Node.js

## 🚦 Getting Started

First, install dependencies:

```bash
pnpm install
# or
npm install
```

Then, run the development server:

```bash
npm run dev
# or
npx next dev --webpack
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
